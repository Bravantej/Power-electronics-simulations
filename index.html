Conventions and quick reference

All devices and sources are ideal: zero voltage drop, instant switching, no source inductance (so no commutation overlap). The supply is vs = Vm sin θ with θ = ωt, Vm = 325 V (230 V rms), 50 Hz. In the three-phase bridge Vm is the phase peak and Vml = √3 Vm ≈ 563 V is the line-to-line peak. The firing angle α is measured from the point where the device would conduct as a diode (natural commutation point). Averages are taken over one period of the output voltage.

With a battery or motor load, the load current is Iavg = (Vavg − E)/R whenever conduction is continuous. The lab shows "Theory Vavg" next to the simulated value for the cases in this table.

1. Single-phase bridge with diodes

D1 and D2 conduct while vs > 0 and D3 and D4 while vs < 0, so the output is the rectified source, vo = |vs|.

Vavg = (1/π) ∫0π Vm sin θ dθ = (Vm/π)[−cos θ]0π = 2Vm/π ≈ 0.637 Vm ≈ 207 V
Vrms = √[(1/π) ∫0π Vm² sin²θ dθ] = Vm/√2

The ripple frequency is 2f = 100 Hz. With a very large L the load current is nearly constant at Io, and the source current is a ±Io square wave.

2. Single-phase fully controlled bridge, continuous current

T1 and T2 fire at α and T3 and T4 at π + α. With a large L, T1 and T2 keep conducting after vs goes negative, until T3 and T4 fire, so vo = vs for α < θ < π + α.

Vavg = (1/π) ∫απ+α Vm sin θ dθ = (Vm/π)[cos α − cos(π + α)] = (2Vm/π) cos α

Vrms = Vm/√2 for any α. For α > 90° the average is negative: the bridge would be inverting, which needs a source E that pushes current against the bridge. With the battery polarity used here the current cannot continue, so the lab shows discontinuous conduction instead.

Power factor. The source current is ±Io, so Is = Io and its fundamental is 4Io/π peak, or 2√2 Io/π rms, lagging by α. Displacement factor = cos α, distortion factor = 2√2/π ≈ 0.9, so PF = (2√2/π) cos α.

3. Single-phase fully controlled bridge, R load

The current is zero whenever vs is zero, so each pair conducts only from α to π.

Vavg = (1/π) ∫απ Vm sin θ dθ = (Vm/π)(1 + cos α)
Vrms² = (1/π) ∫απ Vm² sin²θ dθ = (Vm²/2π)[(π − α) + ½ sin 2α]
Vrms = (Vm/√2) √[1 − α/π + sin 2α/(2π)]

Check: α = 0 gives Vm/√2, and α = π gives 0. Control range is 0 ≤ α ≤ π.

4. Freewheeling diode and the half-controlled bridge

Without help, an inductive load forces the bridge to carry negative vo between π and π + α. A freewheeling diode Df across the load turns on as soon as vo would go negative, so vo = 0 in that interval and the load current circulates through Df.

vo = vs for α < θ < π, and vo = 0 for π < θ < π + α
Vavg = (1/π) ∫απ Vm sin θ dθ = (Vm/π)(1 + cos α)

This is the same as for an R load, and it holds for any L when the current stays continuous. The source current is only present for π − α of each half cycle, so Is,rms = Io √((π − α)/π).

In a half-controlled bridge (two thyristors in the upper row, two diodes in the lower row, or the reverse), freewheeling happens through one thyristor and one diode of the same leg, so no separate Df is needed. Vavg is the same expression, and since vo never goes negative the bridge cannot invert.

5. RLE load (battery charger or DC motor armature)

While a pair conducts, with vo = Vm sin θ:

L di/dt + R i + E = Vm sin ωt → ωL di/dθ + R i = Vm sin θ − E

Let Z = √(R² + ω²L²) and φ = tan⁻¹(ωL/R). The sinusoidal part gives (Vm/Z) sin(θ − φ), the constant part gives −E/R, and the homogeneous part is A e−Rθ/ωL:

i(θ) = (Vm/Z) sin(θ − φ) − E/R + A e−(R/ωL)θ

Conduction can only start once vs exceeds E, so the start angle is θs = max(α, sin⁻¹(E/Vm)). The condition i(θs) = 0 fixes A:

A = [E/R − (Vm/Z) sin(θs − φ)] e(R/ωL)θs

The extinction angle β is the solution of i(β) = 0 (transcendental, so it is found numerically). Conduction is continuous if β ≥ π + θs. When the current is zero, the load terminals sit at E, so over one π-period:

Vavg = (1/π)[Vm(cos θs − cos β) + E(π + θs − β)], Iavg = (Vavg − E)/R

With L = 0: β = π − θs and Iavg = [2Vm cos θs − E(π − 2θs)]/(πR). In the lab, raise E or α and watch the conduction mode switch to "Discontinuous" and the current drop to zero between pulses.

6. Three-phase bridge (six-pulse)

With va = Vm sin θ, vb = Vm sin(θ − 120°) and vc = Vm sin(θ − 240°), the line voltage is, for example, vab = Vml sin(θ + 30°). The upper device connected to the highest phase conducts and the lower device connected to the lowest phase conducts. Each pair conducts for 60°, and vo follows the line-voltage envelope.

Vavg = (3/π) ∫π/32π/3 Vml sin θ dθ = (3Vml/π)[cos 60° − cos 120°] = 3Vml/π = 3√3Vm/π ≈ 538 V
Vrms² = (3Vml²/π)[θ/2 − sin 2θ/4]π/32π/3 = Vml²(½ + 3√3/4π) → Vrms ≈ 0.956 Vml

The ripple frequency is 6f = 300 Hz. Fully controlled: every conduction window shifts by α, and for continuous current

Vavg = (3Vml/π) ∫π/3+α2π/3+α sin θ dθ = (3Vml/π) cos α

With an R load the current is continuous for α ≤ 60°. For 60° < α ≤ 120° the voltage reaches zero at θ = π, so Vavg = (3Vml/π)[1 + cos(α + 60°)]. A half-controlled bridge gives Vavg = (3Vml/2π)(1 + cos α).

Power factor. With a constant load current the source current is ±Io in 120° blocks. Is = Io √(2/3), and the fundamental is (√6/π) Io rms. The distortion factor is 3/π ≈ 0.955 and PF = (3/π) cos α.
